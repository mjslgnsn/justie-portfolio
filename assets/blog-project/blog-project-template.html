The Goal

COACH is a web-based mentoring platform that connects Bataan Peninsula State University mentors with aspiring technology learners. The system provides a structured digital environment for mentorship, collaboration, and skill-based learning.

The platform aims to support effective mentorship through organized sessions, learning resource sharing, and communication tools enhanced with automated SMS notifications for timely updates.

Key Features & Technology

The platform includes role-based access for super administrators, moderators, mentors, and mentees. It supports mentorship scheduling with automated SMS, live video conferencing, and learning resource sharing.

Discussion forums encourage collaborative learning, while feedback and progress tracking monitor user development. Administrative functions include system monitoring, user management, and report generation.

The Result

COACH was successfully developed and evaluated using the ISO/IEC 25010:2011 software quality standard. The system achieved a "Very Acceptable" rating with a 4.46 mean score.

These results demonstrate strong performance across usability, reliability, performance efficiency, and security — indicating the platform effectively meets its intended goals and is suitable for real-world academic deployment.
