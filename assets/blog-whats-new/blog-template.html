Started Learning React and
Modern Frontend Dev

Made it a personal goal to seriously level up in frontend. The shift in thinking from jQuery to JSX was steep — but it changed how I see building for the web entirely.

Setting up my first React project — a lot of terminal, a lot of coffee.

Why React, why now

After building the COACH platform in pure PHP and vanilla JS, I kept running into walls — state management was a mess, UI updates were clunky, and the codebase felt hard to scale. I knew I had to make the leap into component-based thinking.

I chose React not just because it's popular, but because the ecosystem around it — Next.js, Tailwind, Framer Motion, shadcn/ui — genuinely excited me. The idea of building UIs as composable, reusable pieces clicked with how I naturally thought about design.

The biggest mindset shift: moving from "write code that manipulates the DOM" to "describe what the UI should look like at any given state." Once that clicked, everything else followed.

What I covered

I spent the first two weeks on pure React fundamentals — JSX, props, state with useState, effects with useEffect, and component composition. Week three, I moved into Tailwind CSS and immediately fell in love with the utility-first workflow.

Progress check-in

Honest self-assessment after a month of consistent practice — React is still deep, but the fundamentals are locked in. Tailwind already feels natural. The gap I'm closing now is in more complex patterns: context, custom hooks, and optimized re-renders.

What surprised me

I underestimated how much JavaScript fundamentals matter in React. Closures, the event loop, array methods — all of it becomes critical once you're managing state and effects. Going back to solidify those was one of the best decisions I made early on.

Tailwind also surprised me. I was skeptical at first — "isn't this just inline styles?" — but the DX improvement over writing custom CSS is massive once you internalize the scale system. I was hooked within a week.

What's next

The goal is to rebuild part of the COACH frontend in React as a learning project — real-world complexity, real data, real problems. From there, I want to get into Next.js and eventually build a production app with it. The path is clear; now it's about putting in the reps.
